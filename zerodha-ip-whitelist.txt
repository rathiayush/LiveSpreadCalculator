==========================================

This is AuthController.Callback in the code - Kite redirects the browser here with
request_token after a successful login, and it's the only endpoint Zerodha itself needs to
reach. Set it in the developer console under: My Apps -> your app -> Redirect URL.

Local (dev) equivalent - from launchSettings.json:
https://localhost:7105/api/auth/callback
(http://localhost:5159/api/auth/callback if running the http profile instead of https)

IMPORTANT: Kite Connect only supports ONE Redirect URL per app/API key - you can't list both
the production and local URLs on the same app. If you want to test the Kite login flow
locally without disturbing the production app, create a second app in the Kite Connect
developer console (a separate API key/secret) with the localhost Redirect URL above, and use
that key only in local appsettings/user-secrets - never in appsettings.Production.json.

Postback URL: not implemented in this app (no endpoint receives Kite's order-update POSTs) -
leave that field blank unless/until such an endpoint is added.
